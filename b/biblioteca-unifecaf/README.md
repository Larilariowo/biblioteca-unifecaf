# 🐺 Biblioteca Digital UniFECAF 📚

Um projeto acadêmico desenvolvido para a disciplina de **Design Web**, com o objetivo de transformar o protótipo da Biblioteca Digital UniFECAF em uma página moderna, bonita, acessível e adaptável a diferentes telas. 💙

O site foi desenvolvido utilizando **HTML5 e CSS3 puros**, sem frameworks ou construtores de sites, valorizando a organização do código e o aprendizado dos fundamentos do desenvolvimento web.

## ✨ Organização do projeto

📂 **`index.html`**  
Responsável pela estrutura da página, organizando os conteúdos e as seções do site.

🎨 **`css/style.css`**  
Contém as cores, os estilos, a tipografia, os layouts e as adaptações para computadores e smartphones.

🐺 **`assets/imagens/mascote-unifecaf.svg`**  
Ilustração vetorial criada especialmente para o projeto, inspirada no mascote da UniFECAF utilizado como referência.

## 🌷 Como visualizar o site

Não precisa instalar nada! É bem simples:

1. Baixe ou extraia os arquivos do projeto.
2. Abra a pasta `biblioteca-unifecaf`.
3. Dê dois cliques no arquivo `index.html`.
4. Prontinho! O site será aberto no seu navegador. 💻

## 🚀 Como publicar gratuitamente

### 💙 Opção 1 — GitHub Pages

1. Crie um repositório público no [GitHub](https://github.com/).
2. Envie os arquivos do projeto, mantendo a estrutura original das pastas.
3. Acesse **Settings → Pages**.
4. Em *Build and deployment*, selecione a publicação pela branch principal e escolha a pasta raiz (`/root` ou `/`, conforme a opção exibida).
5. Salve as configurações e aguarde a publicação.
6. Quando o site estiver disponível, copie o link público para a entrega acadêmica.

### 💜 Opção 2 — Netlify

1. Acesse o [Netlify](https://www.netlify.com/).
2. Escolha a opção de publicação manual, se disponível na sua conta.
3. Arraste a pasta do projeto já extraída para a área de publicação.
4. Aguarde o processamento e copie o endereço gerado.

## 📚 Observações acadêmicas

Os livros, títulos e descrições apresentados no site são exemplos fictícios, utilizados apenas para demonstrar a organização visual da biblioteca. Eles não representam o catálogo oficial da UniFECAF.

Esta versão corresponde à interface inicial do projeto. Portanto, ainda não possui sistema de busca funcional, login de usuários ou integração com uma base de dados real.

## 🌸 Objetivo do projeto

Demonstrar como um protótipo simples pode se transformar em uma experiência web mais agradável, organizada e acessível, utilizando os fundamentos de HTML e CSS, uma identidade visual consistente e recursos de responsividade.

**Desenvolvido com dedicação para a disciplina de Design Web.** 💙📖
