# Biblioteca Digital UniFECAF

Projeto acadêmico de Design Web desenvolvido com HTML5 e CSS3, sem frameworks ou construtores.

## Estrutura
- `index.html`: estrutura semântica da página.
- `css/style.css`: identidade visual, layout e regras responsivas.
- `assets/imagens/mascote-unifecaf.svg`: ilustração vetorial original inspirada no mascote mostrado como referência.

## Como abrir
Abra `index.html` em um navegador. Não há dependências nem instalação necessária.

## Publicação gratuita
**GitHub Pages:** crie um repositório público, envie os arquivos mantendo a estrutura de pastas, acesse Settings → Pages, selecione a branch principal e a pasta raiz e salve. Aguarde a publicação para copiar o link público.

**Netlify:** acesse Netlify, escolha a opção de publicar manualmente e arraste a pasta do projeto (ou envie o ZIP descompactado). Copie a URL pública gerada.

## Observação acadêmica
Os livros e descrições são exemplos fictícios para demonstrar a interface; não representam o catálogo real da instituição. O site é uma interface inicial e não implementa busca real, login ou integração com acervo.
